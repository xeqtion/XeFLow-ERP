# Troubleshooting

## Login Shows "请求失败"

Check these in order:

1. Backend is running on `http://localhost:8080/api`.
2. Frontend dev proxy points to the backend in `erp-frontend/vite.config.ts`.
3. MySQL is running and the configured `MYSQL_DB` exists.
4. The user exists and is enabled.
5. Browser devtools network tab shows whether `/api/auth/login` is connection refused, 401, 403 or 500.

Useful commands:

```powershell
Get-NetTCPConnection -LocalPort 8080,5173 -State Listen
curl http://localhost:8080/api/actuator/health
```

## Port Already in Use

```powershell
Get-NetTCPConnection -LocalPort 8080,5173 -State Listen |
  Select-Object LocalPort,OwningProcess
Stop-Process -Id <PID> -Force
```

Or use:

```powershell
./stop-dev.ps1
```

## MySQL Cannot Connect

- Confirm MySQL service or local server process is running.
- Confirm the password used by backend matches `MYSQL_USER` and `MYSQL_PASSWORD`.
- Use UTF-8 when importing scripts:

```powershell
mysql -u <user> -p --default-character-set=utf8mb4 -e "SELECT 1"
```

## Frontend Starts but API Fails

- Confirm backend started successfully.
- Confirm backend context path is `/api`.
- Confirm `VITE_API_TARGET` is not pointing to an old backend.
- Clear browser storage if an old invalid token is cached.

## Registration Code or Email Verification Fails

- `ERP_REGISTER_ENABLED=false` means registration is closed.
- Registration requires a valid invitation code generated by an administrator.
- `ERP_REGISTER_REQUIRE_EMAIL_CODE=true` requires working SMTP settings.
- `ERP_MAIL_EXPOSE_CODE` must remain false outside local development.

## Screenshots Are Empty

- Load local sample data from `docs/sample-data/docs_sample_data.sql`.
- Login as `admin`.
- Refresh the page after sample data import.
- Check whether the current role has the required menu permissions.

## Generated Documents Cannot Download

- Check backend upload/document directories.
- Check the source business record is visible to the logged-in user.
- Check browser download blocking rules.
- Check backend logs for template or file path errors.
